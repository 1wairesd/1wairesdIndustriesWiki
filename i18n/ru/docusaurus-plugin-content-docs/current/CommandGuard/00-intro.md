# CommandGuard

**CommandGuard** управляет тем, какие команды игроки видят и могут выполнять на
вашем сервере. Он работает сразу на двух уровнях:

- **Блокировка команд** — заблокированная команда не выполняется, вместо неё
  срабатывает настроенное действие (сообщение, звук, title, консольная команда,
  эффект зелья).
- **Фильтрация tab-complete** — в списке автодополнения игрок видит только
  разрешённые ему команды. Скрытые команды не появляются даже в подсказках.

Работает на отдельном сервере Spigot/Paper и на прокси Velocity.

## Платформы

| Платформа       | Версии  |
|-----------------|---------|
| Paper / Spigot  | 1.16.5+ |
| Velocity        | 3.x     |

Минимальная версия Java зависит от платформы: Spigot — Java 17, Velocity — Java 21.

## Spigot или Velocity — кто за что отвечает

Каждая версия работает со своим набором команд:

- **Spigot (бэкенд)** отвечает за команды бэкенд-сервера. Блокирует любой ввод
  игрока по списку из `config.yml` и фильтрует tab-complete для команд,
  зарегистрированных на этом сервере.
- **Velocity (прокси)** отвечает **только за команды прокси** (зарегистрированные
  на самом Velocity). Команды бэкенда прокси не трогает — ими занимается Spigot.

Если плагин стоит и там, и там, они не дублируют работу, а дополняют друг друга.
Подробнее — в разделе [Работа в сети](./04-network.md).

## Основные возможности

- **Фильтрация tab-complete** — игрок видит только разрешённые ему команды.
- **Блокировка команд** с действиями: `message`, `title`, `sound`,
  `console_command`, `give_potion_effect`.
- **Режим белого списка** — разрешить только определённые команды, остальное
  заблокировать.
- **Группы прав** с приоритетом, наследованием (`extends`) и слиянием групп
  одинакового приоритета.
- **Группы для отдельных серверов** (`servers`) — разные списки tab на разных
  бэкендах (только прокси).
- **TabSync между серверами** — прокси отправляет разрешённый список прокси-команд
  на бэкенд через plugin messaging.
- **Защита от spy-клиентов** — фильтрует сырые пакеты TAB_COMPLETE, чтобы
  чит-клиенты не могли узнать скрытые команды.
- **Многоязычность** — в комплекте `en_EN` и `ru_RU`, свои языки добавляются в
  `plugins/CommandGuard/lang/`.
- **Блокировка команд с двоеточием** — при желании блокирует все обходы вида
  `namespace:command`.
