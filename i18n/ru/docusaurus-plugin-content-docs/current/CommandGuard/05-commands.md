# Команды

Все команды требуют право `commandguard.admin`.

## Spigot

| Команда | Описание |
|---------|----------|
| `/cg reload` | Перезагрузить конфиг и обновить tab всем игрокам |
| `/cg check <игрок>` | Показать активную tab-группу и разрешённые команды игрока |
| `/cg updategroup <игрок>` | Отправить игроку обновлённый список tab |

Алиас команды: `/cg` (полное имя — `/commandguard`).

## Velocity

| Команда | Описание |
|---------|----------|
| `/cgv reload` | Перезагрузить конфиг и отправить TabSync всем онлайн-игрокам |
| `/cgv check <игрок>` | Показать активную tab-группу и разрешённые команды игрока |
| `/cgv updategroup <игрок>` | Отправить игроку TabSync |

:::tip
`/cg check` удобен для диагностики: показывает, какую группу и сколько команд
сейчас видит конкретный игрок.
:::
